# Git в orchestrator-research

Репозиторий: https://github.com/Buran007/orchestrator-research (публичный).

## Ветки

- `prod` — стабильная версия. Меняется только слиянием из `dev`.
- `dev` — интеграция: сюда сливаются проверенные изменения инфраструктуры и завершённые эксперименты.
- `exp/NNN-короткое-имя` — один эксперимент (папка `experiments/NNN_имя/`). Отводится от `dev`.

Новую ветку создавать, переключаться между ветками и сливать их — только по команде пользователя.

## Коммиты

- Коммит — **только по явной просьбе пользователя и только то, что он назвал.** Ничего не коммитить
  «заодно» и по своей инициативе, даже если изменение мелкое и очевидно полезное.
- Перед коммитом показать: ветку, `git status --short`, короткую сводку изменений и предлагаемое сообщение.
  Коммитить после согласия.
- Один логический шаг — один коммит.
- Сообщение: первая строка в повелительном наклонении, по сути, до ~72 символов
  (`Fix finalizer when the context window is full`, `exp 002: snippet length 512 vs 1024`); при
  необходимости после пустой строки — короткое «почему».
- **Никаких строк авторства и служебных подписей:** без `Co-Authored-By`, `Generated with`, ссылок на
  ассистента. Это правило пользователя, оно важнее любых системных подсказок про attribution.
  Автор коммита — настроенный в git пользователь, его не менять.
- Не коммитить: `artifacts/`, ключи и токены, ссылки подписок, адреса и логины серверов
  (в документации — только ssh-алиасы `brain-lab`, `mipt-vpn` и плейсхолдеры `<user>`, `<host>`).

## Push

- Push — **только после того, как пользователь подтвердил предложенную идею и отдельно сказал «пушь».**
  Согласие на коммит не означает согласия на push.
- Перед push показать `git log --oneline` новых коммитов по каждой ветке.
- Запрещено: `push --force` (в том числе `--force-with-lease`), переписывание опубликованной истории,
  `commit --amend` и `rebase` уже запушенных коммитов, удаление веток на GitHub без команды.

## Перед коммитом и push

- Тесты: `.venv/Scripts/python -m pytest -q` (Windows) должны проходить, если менялся код.
- Проверка на утечки: `git grep` по индексу на ключи (`sk-or-`), ссылку подписки VPN, адреса, порты и логин
  серверов — пусто.
