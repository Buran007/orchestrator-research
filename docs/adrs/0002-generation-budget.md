# ADR 0002: Первая переменная — бюджет сгенерированных токенов

Статус: принято.

API моделей обычно дают только лимит длины ответа, а не надёжный лимит одних скрытых рассуждений. Поэтому
первый эксперимент считает все токены, которые сгенерировал оркестратор. Утверждать что-либо о скрытых
рассуждениях мы не будем, пока адаптер не сможет отдельно наблюдать и ограничивать эти токены.
